Wireframe annotations and scope
  1. Account entry point; this page does not change the clinical workspace.
  2. Only authorised organisations; references distinguish identical names.
  3. Clinic cards use the scoped list response. Full references are read-only details.
  4. Separate organisation/clinic commands; a clinic is not auto-created or billed.
  5. One name field; parent stays fixed. Unknown result retries the same intent.
  6. Design controls simulate outcomes; no API, credentials, storage or real account is used.
